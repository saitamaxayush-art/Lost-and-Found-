# Lost and Found Portal

A campus Lost & Found portal to report lost items, report found items, search/filter items, and track item recovery statuses.

## Repository Structure

```text
Lost-and-Found-/
├── frontend/          # React + Vite frontend web application
```

## Getting Started

### Frontend

Navigate to the `frontend` directory:

```bash
cd frontend
npm install
npm run dev
```

For more information on frontend features, state management, and running locally, see [`frontend/README.md`](frontend/README.md).
